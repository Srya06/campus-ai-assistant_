  CAMPUS AI ASSISTANT - QUICK RUN INSTRUCTIONS
===================================================================

Option A (Recommended - Single Unified Server):
-------------------------------------------------------------------
Both Frontend and Backend run together on Port 8000!

1. Open PowerShell / Command Prompt:
   cd campus-ai-assistant
   .\venv\Scripts\activate
   uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000

2. Open in your browser:
   👉 http://localhost:8000

* Full Web Application: http://localhost:8000
* Interactive Swagger API Docs: http://localhost:8000/docs


Option B (Separate Frontend Server on Port 3001):
-------------------------------------------------------------------
If you prefer running frontend on a dedicated static server:

Terminal 1 (Backend):
   uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000

Terminal 2 (Frontend):
   python -m http.server 3001 --directory frontend

Visit:
   👉 http://localhost:3001
